# IT3130 Git Basics Lab

## Purpose
This repository demonstrates a basic Git workflow for IT3130.

## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation

## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push

## What I learned
I learned that staging allows me to choose which changes I want to commit, while a commit permanently records those selected changes in the local repository. I also learned that a remote connects my local repository to GitHub so I can push my commits online.

## Pair Collaboration

This repository was used to practise GitHub collaboration through feature branches, pull requests, peer review, and merging.
